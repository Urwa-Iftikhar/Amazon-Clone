# Amazon Clone  

This is a simple **Amazon Clone** project created using "HTML, CSS".  
The project replicates the basic UI of the Amazon website, including header, banner, product sections, and footer.  

## Features  
- Responsive header with Amazon-style navigation bar  
- Product cards with image, and title.  
- "See More" functionality for content  
- Footer section styled similar to Amazon  

## Project Structure  
- `index.html` → Main file containing the structure of the website  
- `style.css` → Contains all the styling for layout and design
